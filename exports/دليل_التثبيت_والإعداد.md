## 🛠️ الخطوة 1: تثبيت الإضافة في Antigravity IDE

1. افتح برنامج **Antigravity**.
2. توجّه إلى لوحة الإضافات **Extensions** من الشريط الجانبي الأيسر (أو اضغط الاختصار `Ctrl + Shift + X`).
3. انقر على أيقونة **النقاط الثلاث (`...`)** في الزاوية العلوية لنافذة الإضافات (*Views and More Actions*).
4. اختر من القائمة: **Install from VSIX...**
5. تصفّح مجلد المشروع واختر الملف:
   ```
   C:\Users\Aseel\Desktop\antigravity-telegram-control-main\exports\antigravity-telegram-control-1.0.14.vsix
   ```
6. انتظر ثوانٍ معدودة؛ ستظهر لك رسالة تأكيد في الزاوية السفلية للمحرر:
   > *Successfully installed the extension 'Antigravity Telegram Control'!*

## 🤖 الخطوة 2: إنشاء بوت التلجرام عبر `@BotFather`

1. افتح تطبيق **Telegram** على هاتفك أو حاسوبك.
2. في خانة البحث، ابحث عن الحساب الرسمي الموثّق: **`@BotFather`** (ستجد بجانبه علامة التوثيق الزرقاء).
3. اضغط **Start** ثم أرسل الأمر:
   ```text
   /newbot
   ```
4. سيطلب منك إدخال اسم ظاهري للبوت (Display Name):
   - مثال: `Antigravity Assistant`
5. سيطلب منك إدخال اسم مستخدم (Username) للبوت ويجب أن ينتهي بكلمة `bot`:
   - مثال: `aseel_antigravity_bot`
6. سيقوم `@BotFather` بتهنئتك وتوليد رمز الوصول البرمجي الخاص بك (**HTTP API Token**):
   ```text
   7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
7. **احفظ هذا الرمز (Token)**؛ سنحتاجه في الخطوة التالية.

## ⚡ الخطوة 3: تشغيل Antigravity مع منفذ التصحيح (Debug Port)

> [!IMPORTANT]
> لكي تتمكن الإضافة من قراءة نافذة الوكيل (Agent)، توسيع التغييرات (`/expand`)، قراءة الكوتا (`/status`)، والتقاط الشاشات عبر بروتوكول Chrome DevTools (CDP)، يجب تشغيل Antigravity ومعه معامل المنفذ `9222`.

### الطريقة السريعة (اختصار سطح المكتب):
1. انقر بالزر الأيمن على اختصار **Antigravity** على سطح المكتب واذهب إلى **الخصائص (Properties)**.
2. في تبويب **Shortcut**، توجّه إلى حقل **الهدف (Target)**.
3. في نهاية المسار (بعد علامات التنصيص)، أضف مسافة ثم ضع:
   ```text
   --remote-debugging-port=9222
   ```
   *(مثال: `"C:\Users\Aseel\AppData\Local\Programs\Antigravity\Antigravity.exe" --remote-debugging-port=9222`)*
4. اضغط **تطبيق (Apply)** ثم **موافق (OK)**، ثم شغّل البرنامج من هذا الاختصار.

### أو من خلال سطر الأوامر (PowerShell / Terminal):
```powershell
antigravity --remote-debugging-port=9222
```

## 🔗 الخطوة 4: ربط البوت بالإعدادات وتشغيله

1. في محرر **Antigravity**، افتح شاشة الإعدادات بالضغط على:
   `Ctrl + ,`
2. في شريط البحث بالأعلى، اكتب: `Antigravity Telegram Control`.
3. اضبط الإعدادات التالية:
   * **`Bot Token`**: الصق رمز الـ Token الذي حصلت عليه من `@BotFather`.
   * **`Debugging Port`**: تأكد من أنه `9222`.
   * **`Language`**: اختر لغة واجهة البوت (`ar` للعربية أو `en` للإنجليزية).
4. **تشغيل البوت لأول مرة**:
   - اضغط `Ctrl + Shift + P` لفتح لوحة الأوامر واكتب:
     ```text
     Telegram: Start Bot
     ```
   - سيظهر إشعار يؤكد أن البوت بدأ العمل بنجاح.
5. **تحديد الـ Allowed Chat ID (أمان تام)**:
   - افتح البوت في التلجرام واضغط **Start** أو أرسل له: `/start`.
   - سيرد عليك البوت بمعرف المحادثة الخاص بك (**Chat ID**):
     *(مثال: `Your Chat ID is: 123456789`)*.
   - انسخ هذا الرقم وارجع لإعدادات الإضافة في المحرر والصقه في:
     **`antigravityTelegramControl.allowedChatId`**.
   - *(هذا يضمن ألا يستطيع أي شخص آخر غيرك إرسال أوامر للبوت أو التحكم بحاسوبك)*.
6. **تسجيل أوامر التلجرام تلقائياً (Register Slash Commands)**:
   - اضغط `Ctrl + Shift + P` في المحرر واكتب:
     ```text
     Telegram: Register Slash Commands
     ```
   - الآن عندما تفتح البوت في التلجرام وتكتب `/`، ستظهر لك كل الأوامر مسجلة بأوصافها الرسمية تلقائياً!

## 🎮 الخطوة 5: كيفية الاستخدام وأهم الأوامر الجديدة

| الأمر | الوظيفة |
| :--- | :--- |
| **`/menu`** أو **`/start`** | **ويدجت لوحة الأوامر التفاعلية**: أزرار وأيقونات ملونة ومصنفة (حالة، ملفات، إضافات، إلخ) مع إمكانية البحث الفوري عن أي أمر دون الحاجة لكتابته يدوياً! |
| **`/status`** | **لوحة الحالة الشاملة**: تقرير لحظي يجمع كوتا الذكاء الاصطناعي، حالة الوكيل، وموارد الجهاز (المعالج والرام ووقت التشغيل). |
| **`/files`** | **متصفح الملفات التفاعلي**: استعراض مجلدات المشروع المفتوح من الهاتف مع أزرار التنقل السلس. |
| **`/getfile <المسار>`** | **جلب أي ملف إلى الهاتف**: إرسال الملف فوراً لمحادثتك (صور، مستندات حتى 50MB، أو نصوص منسقة). |
| **`/extensions`** | **لوحة الإضافات الجانبية**: استعراض إضافات VS Code (مثل GitHub Actions, Git) والتقاط صورة مباشرة لشاشاتها. |
| **`/expand`** | **توسيع تغييرات المحادثة لحظياً**: فتح جميع التفاصيل والقوائم المطوية تحت أسهم الشات وإرسال لقطة شاشة واضحة لها. |
| **`/changes`** | **ملخص التغييرات البرمجية**: استخراج قائمة بالملفات المعدلة والأوامر المنفذة في المحادثة الحالية. |
| **`/history [عدد]`** | **سجل المحادثة**: استرجاع آخر رسائل متبادلة مع الوكيل في الشات. |
| **`/answer [نص]`** | **الرد على الأسئلة**: الإجابة على استفسارات الوكيل، مع وجود أزرار تفاعلية فورية وزر `📸 Context Frame`. |
| **`/screenshot`** | التقاط صورة فورية لشاشة المحرر الحالية. |
| **`/ask <سؤال>`** | إرسال توجيه أو استفسار جديد لوكيل الذكاء الاصطناعي وتنفيذه مباشرة. |

## 💡 نصائح لحل المشاكل الشائعة

* **البوت لا يلتقط الشات أو يظهر خطأ "Cannot connect to debugging port"**:
  - تأكد من إغلاق Antigravity بالكامل وتشغيله مجدداً باستخدام المعامل:
    `--remote-debugging-port=9222`.
* **البوت لا يستجيب في التلجرام**:
  - تأكد من أن الـ `Bot Token` مدخل بشكل صحيح بدون أي مسافات زائدة.
  - تأكد من تشغيل البوت عبر الأمر `Telegram: Start Bot`.
* **رسالة "Access denied"**:
  - تأكد من أن رقم الـ `Chat ID` الخاص بك في التلجرام مسجل في خانة `Allowed Chat ID` في إعدادات الإضافة.

مبروك! الآن مشروعك بالكامل تحت سيطرتك من هاتفك عبر التلجرام بكل سهولة واحترافية. 🎉
